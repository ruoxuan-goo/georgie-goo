# Georgie Goo – Resume

One-page resume landing page built with Next.js, React and Tailwind CSS.

Resume content lives in `src/app/resume.ts`; the page layout is in `src/app/page.tsx`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static export to ./out
```

Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
